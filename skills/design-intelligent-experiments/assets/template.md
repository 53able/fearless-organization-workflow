## 引継ぎ

| 項目 | 記入 |
| --- | --- |
| 観測事実 | 確認できた出来事・日時・状態。識別情報は必要最小限 |
| 解釈・仮説 | 根拠と代替説明。事実と区別 |
| 不足情報 | 未確認事項・確認方法・確認担当 |
| 必要な人の判断 | 判断事項・実際の権限者・期限。未定なら未定 |
