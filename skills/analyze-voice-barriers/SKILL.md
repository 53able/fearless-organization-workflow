# 発言障壁の分析

## 必要な入力

言いにくい内容、相手・観衆・地位差、予想する不利益、過去の応答とその後の対応、徒労感、暗黙ルール、本人が選べる経路、共有可能な範囲。

## 手順

1. [障壁の見分け方](references/principles.md)を読み、具体的な一場面から始める。言わなかった内容は本人が共有できる範囲で扱い、沈黙の理由を外から断定しない。
2. 観察された応答、本人の経験、予想、伝聞を分ける。相手・観衆・地位差が変わると何が変わるかを確かめる。
3. 無知・無能・邪魔と見られる恐れ、関係悪化、不利益、徒労感、暗黙ルールを別欄に整理する。複数が併存する場合は一つに還元しない。
4. 発信者の言い方だけでなく、受け手が変えられる応答・相談時間・検討責任・採否の説明・追跡条件を特定する。「言っても変わらない」には過去の放置と決定後の返答を確認する。
5. 非公開、非同期、少人数、適切な代替相談先を比較し、各経路のアクセス・記録・閲覧者・対応担当・限界を示す。本人に発言・自己開示を強制しない。
6. [場面別障壁表](assets/template.md)で改善候補と確認条件を返す。報復や加害の疑いがある場合は公開発言の提案を止め `review-reporting-and-fair-boundaries` へ。放置への対応は `respond-to-warnings`、傷ついた対話の修復は `renew-psychological-safety` へ引き継ぐ。

## 境界と完了条件

共有可能な最小限の情報を使い、氏名・少人数から特定できる情報は必要に応じて役割名へ置き換える。共有範囲・本人の意向が不明なら公開・送信を保留し、限定した下書きを作る。匿名性や報復がないことを保証しない。

未知の経験・過去の応答・判断権者を補完せず「未確認」とする。資料整理の権限だけで制度変更・処分・採否を承認済み／実施済みにしない。権限者の判断が必要な箇所と、今できる準備を分ける。

成果物に担当・期限または再確認条件・共有範囲が入り、事実と仮説が区別できたら資料作成を完了する。対話・制度改善そのものの完了とは区別する。必要条件が欠ける場合は該当判断を保留し、確認先・未解消事項を残す。
