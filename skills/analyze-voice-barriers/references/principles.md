# 発言障壁の分析の判断原則

## 沈黙を説明する仮説

| 仮説 | 確認する具体例 | 受け手側の変更候補 |
| --- | --- | --- |
| 印象管理 | 質問すると無知、失敗を話すと無能、提案すると邪魔と思われるか | 未完成の疑問を歓迎し、相手の価値と内容の採否を分ける |
| 関係・面子 | 上司が作った計画、上司の上司がいる場で話しにくいか | 受け手が反証を求める、別経路を選べるようにする |
| 不利益 | 評価、配置、仕事、人間関係への懸念と既往 | 利害関係と相談経路を点検し、保証ではなく対応条件を確認する |
| 徒労感 | 受け付けられたが放置、理由も返答もないか | 検討担当と期限、採否理由、追跡を置く |
| 暗黙ルール | 完全な証拠がないと話せない、上位者を公に訂正できないという期待 | 暫定的懸念の扱いを明示し、実際の応答と照合する |

発言の組織的便益は将来で不確実なのに、沈黙の自己防衛はその場ですぐ得られる。この非対称性を認め、説得で勇気だけを増やそうとしない。報復の記録が見つからないことは、不利益がない証明にならない。

## 例と反例

- 改善案を持つ技術者が生活費への心配から黙る一方、解雇の実例は知らない。恐れを虚偽と扱わず、経験と反応予期、暗黙のルールを分けて確認する。
- 上司の上司が同席すると訂正を控える。本人の性格を変えるより、受け手が訂正を招く条件と別経路を比較する。
- 同じ懸念を何度も受け付けて放置しているのに質問文だけを柔らかくするのは反例。検討・返答の責任者と追跡が必要になる。
