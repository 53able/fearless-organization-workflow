## 引継ぎ

| 項目 | 記入 |
| --- | --- |
| 観測事実 | 確認できた出来事・日時・状態。識別情報は必要最小限 |
| 解釈・仮説 | 根拠と代替説明。事実と区別 |
| 不足情報 | 未確認事項・確認方法・確認担当 |
| 必要な人の判断 | 判断事項・実際の権限者・期限。未定なら未定 |
| 次の担当 | 担当・次の行動・期限・受領確認。未確認なら未確認 |
| 未解消事項 | 残る危険・懸念・異論・依存関係 |
| 再確認条件 | 時点または条件・見る指標・再提起先 |
| 共有範囲 | 許可された受け手・除く識別情報・未確認の許可 |
