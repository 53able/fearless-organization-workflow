# 課題の振り分け

必要な行だけを使い、該当スキルの入力・停止条件を読む。インストールされていない専門スキルは存在すると扱わず、判断待ちの担当候補として記録する。

| 課題 | スキル | 使用条件 |
|---|---|---|
| 概念と適用条件の整理 | [clarify-psychological-safety](../../clarify-psychological-safety/SKILL.md) | 「優しくすると基準が下がる」「信頼しているから安全」「発言が少ない人は内向的」などの混同がある。 |
| 発言障壁の分析 | [analyze-voice-barriers](../../analyze-voice-barriers/SKILL.md) | 懸念が上がらない、会議後に異論が出る、同じ問題への相談が遅れる。 |
| 目的・基準・目標圧力の設計 | [design-learning-accountability](../../design-learning-accountability/SKILL.md) | 案件開始、未達の反復、達成圧力、倫理と報酬の矛盾、戦略の現実との乖離。 |
| 質問・傾聴・参加の設計 | [design-inquiry-and-participation](../../design-inquiry-and-participation/SKILL.md) | 会議、1on1、現場改善、上位者だけが話す場。 |
| 率直なレビューとフィードバック | [facilitate-candid-feedback](../../facilitate-candid-feedback/SKILL.md) | 未完成品の検討、意見の対立、貢献を妨げる言動へのフィードバック。 |
| 警告・悪い知らせへの対応 | [respond-to-warnings](../../respond-to-warnings/SKILL.md) | 異常、遅延、未遂、未解消の懸念、追加情報の要求。 |
| 失敗分析と工程学習 | [learn-from-failures](../../learn-from-failures/SKILL.md) | 障害・失敗後、応急策の常態化、工程間で負担が移る場合。 |
| 知的な実験と撤退判断 | [design-intelligent-experiments](../../design-intelligent-experiments/SKILL.md) | 新規案の成立条件が未知、継続が慣性化している。 |
| 協働・引継ぎ・相互学習 | [design-teaming-and-knowledge-sharing](../../design-teaming-and-knowledge-sharing/SKILL.md) | 専門・部門・距離を越える仕事、緊急交信、日常の知識交換。 |
| 独立した申告経路と公正な境界 | [review-reporting-and-fair-boundaries](../../review-reporting-and-fair-boundaries/SKILL.md) | 申告先の利害関係、高業績者の例外扱い、監督の情報依存、規則の曖昧さ。 |
| 多様性・包摂・所属感 | [design-inclusive-contribution](../../design-inclusive-contribution/SKILL.md) | 多様な人を採用したが意見が使われない、特定の人だけが参加する、所属感に懸念がある。 |
| 従業員への配慮の制度化 | [design-employee-care-practices](../../design-employee-care-practices/SKILL.md) | 善意の対話があるのに負担や資源の矛盾が残る、信頼を損なう慣行、育成不足。 |
| 測定・聞き取り・証拠解釈 | [assess-psychological-safety-evidence](../../assess-psychological-safety-evidence/SKILL.md) | 尺度選定・採点、集団の状態の確認、報告数の変化、改善の追跡。 |
| 修復・練習・継続改善 | [renew-psychological-safety](../../renew-psychological-safety/SKILL.md) | 威圧的応答、不適切な冗談、リーダー交代、制度の形骸化、改善後の再点検。 |

緊急危険は respond-to-warnings と既存の専門対応、加害・報復・利益相反は review-reporting-and-fair-boundaries を優先する。採点仕様の不明は assess-psychological-safety-evidence で保留する。単一課題はその専門スキルへ直接つなぐ。
